      Settings

      Server Sync

      Connect to a remote server to sync your planner across devices.

      No server yet? You can host your own for free. Get it on GitHub: github.com/RustColeone/memora

      HTTP is not encrypted. Another device on this network may observe or modify synced planner data and passwords. Use HTTPS whenever possible; use HTTP only for a server and network you trust.

      Required only if the server is configured with a password. Use HTTPS so it stays private in transit.

      Data Backup

      Export or import your whole database (memos, finance and planner) including images and attachments. A backup always covers every page, whichever one you're on.
