Advanced metadata

Edits are written into the image's own embedded metadata (EXIF). A copy of the original is kept so you can revert at any time. Privacy removal covers EXIF GPS data and selected camera identifiers only; XMP and IPTC are not changed.

Embedded-metadata editing is available for JPEG images.
